# S6.9 - Notes de validation locale

`scripts/preflight_local.sh --quick` reste le parcours rapide. Il sert a
verifier les controles locaux essentiels sans lancer les smokes plus longs :
OpenAPI, smoke applicatif principal et controles legers. C'est le mode a
privilegier pendant les boucles courtes de developpement.

`scripts/preflight_local.sh --full` sert a valider une routine locale plus
complete avant de considerer un lot pret. Il conserve les controles rapides et
ajoute les validations plus couteuses ou plus ciblees, dont le smoke de reprise
employe `MuniConversion`.

Le smoke `scripts/smoke_muni_conversion_employee_resume.sh` est reserve a
`--full` parce qu'il demarre un scenario plus complet : premier run
`skip_existing`, reprise employe, relance `rename_with_suffix`, verification
des sorties et verification du contrat canonique. Cette couverture est utile
avant cloture, mais elle ne doit pas ralentir le parcours rapide.

Recommandation locale :

- lancer `--quick` pendant les changements courants ou apres une petite
  modification sans impact attendu sur les smokes longs ;
- lancer `--full` avant de cloturer un lot qui touche la validation locale,
  les facades Muni ou le comportement de reprise employe `MuniConversion`.
