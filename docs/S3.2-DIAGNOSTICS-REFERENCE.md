Date: 2026-04-16  
Scope: referentiel operatoire commun (documentation uniquement)

## Objet
Definir une base unique et stable pour interpreter les diagnostics de la chaine:
- MuniAnalyse
- MuniRegles
- MuniRenommage
- Orchiviste (pilotage/historique)

Ce referentiel sert de base future pour harmoniser UI, messages operateurs et regles de decision, sans changement de code dans ce lot.

## Convention minimale
- Severite operatoire:
  - `info`: informatif, pas bloquant
  - `warning`: revue humaine recommandee avant apply
  - `blocking`: apply interdit tant que non resolu
- Decision attendue:
  - `Go`
  - `No-Go`
  - `Review required`

## Classification explicite pour apply

### Diagnostics purement informatifs
- `RN_IDEMPOTENT_NOOP`

### Diagnostics bloquants pour apply
- `RG_BUNDLE_UNREADABLE_OR_INVALID`
- `RG_RULE_NOT_FOUND_OR_NOT_APPLICABLE`
- `RG_REQUIRED_METADATA_FIELDS_MISSING`
- `RN_PLAN_DIGEST_MISMATCH`
- `RN_COLLISION_BLOCKING`
- `RN_DESTRUCTIVE_GUARD_MISSING`

### Diagnostics necessitant revue humaine
- `AN_EXTRACTION_WARNING_STRUCTURED`
- `AN_EXTRACTION_PROVENANCE_FALLBACK`
- `RG_FALLBACK_REASON_PRESENT`

---

## Regle de decision operatoire
Avant `apply`, la decision par defaut est:
1. Si un diagnostic `blocking` est present -> `No-Go`.
2. Sinon, si au moins un diagnostic `warning` est present -> `Review required`.
3. Sinon -> `Go`.

## Tableau court de decision

| Symptome | Diagnostic attendu | Action immediate | Decision |
| --- | --- | --- | --- |
| Warnings extraction visibles | `AN_EXTRACTION_WARNING_STRUCTURED` / `AN_EXTRACTION_PROVENANCE_FALLBACK` | Revue humaine de qualite metadata | Review required |
| Fallback regles constate | `RG_FALLBACK_REASON_PRESENT` | Verifier cause fallback, valider ou corriger | Review required |
| Rule contract casse | `RG_BUNDLE_UNREADABLE_OR_INVALID` / `RG_RULE_NOT_FOUND_OR_NOT_APPLICABLE` / `RG_REQUIRED_METADATA_FIELDS_MISSING` | Corriger bundle/regle/metadata puis re-preview | No-Go |
| Integrity gate echoue | `RN_PLAN_DIGEST_MISMATCH` | Regenerer preview et digest frais | No-Go |
| Conflits cibles detectes | `RN_COLLISION_BLOCKING` | Resoudre collisions avant apply | No-Go |
| Fichiers deja conformes | `RN_IDEMPOTENT_NOOP` | Confirmer no-op attendu | Go |
